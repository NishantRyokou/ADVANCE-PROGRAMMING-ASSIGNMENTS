## 📊 Project Overview

### What is Assignment 19?
A React Native mobile application that demonstrates:
- State management with hooks
- Counter logic with validation
- Dynamic theme switching
- Flexbox layout
- Mobile app best practices

### Key Features
- ✅ Counter (increment/decrement/reset)
- ✅ Validation (no negative numbers)

- ✅ Theme toggle

## 🎯 How to Run

### Step 1: Install
```bash
cd Assignment19
npm install --legacy-peer-deps
```

### Step 2: Start
```bash
npm start
```

### Step 3: Choose Platform
- Press `w` for web
- Press `a` for Android
- Press `i` for iOS
- Scan QR for Expo Go

## 🔧 Troubleshooting

### Common Issues

**Dependencies won't install**
```bash
npm install --legacy-peer-deps
```

**Port already in use**
```bash
npm start -- --port 19001
```

**Blank screen**
Press `r` to reload

**Metro Bundler error**
```bash
npm start -- --reset-cache
```

→ See **QUICK_START.md** for more
