================================================================================
                         KEY CONCEPTS
================================================================================

REFERENCE COUNTING:
  - Every object has a reference count
  - When count reaches 0, object is deallocated
  - Immediate cleanup

CIRCULAR REFERENCES:
  - Objects reference each other
  - Prevents reference count from reaching 0
  - Objects remain in memory indefinitely

GARBAGE COLLECTION:
  - Detects unreachable cycles
  - Deallocates unreachable cyclic objects
  - Periodic or on-demand cleanup

CYCLE TYPES:
  - Simple cycle: A -> B -> A
  - Self-reference: A -> A
  - Complex cycle: A -> B -> C -> A
