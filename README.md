# Assignment 1: Time Complexity Analysis

Write a C program to analyze time complexities in constant time, linear time and quadratic time. Increase the size of input to check the time consumed.

## Implementation Details

The C program implemented in [Assignment1/time_complexity.c](file:///c:/Users/legam/Documents/btech/A.P/Assignment1/time_complexity.c) executes and measures the time taken by:
1. **Constant Time ($O(1)$)**: Access/arithmetic operation that runs in fixed time regardless of input size.
2. **Linear Time ($O(N)$)**: A single loop that scales proportionally with the size of $N$.
3. **Quadratic Time ($O(N^2)$)**: A nested loop that scales with the square of the size of $N$.
