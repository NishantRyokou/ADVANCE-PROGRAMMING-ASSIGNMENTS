# Assignment 2: Analyze Space Complexities in C

Write a C program for three different operations as stated in question 1 to analyze the space complexity.

## How to Compile and Run

1. Open your terminal in the workspace directory.
2. Compile the C source file:
   ```bash
   gcc Assignment2/space_complexity.c -o Assignment2/space_complexity.exe
   ```
3. Run the compiled executable:
   ```bash
   ./Assignment2/space_complexity.exe
   ```
