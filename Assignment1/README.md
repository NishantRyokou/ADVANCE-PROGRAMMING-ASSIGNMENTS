# Assignment 1: Analyze Time Complexities in C

Write a C program to analyze time complexities in constant time, linear time and quadratic time. Increase the size of input to check the time consumed.

## How to Compile and Run

1. Open your terminal in the workspace directory.
2. Compile the C source file:
   ```bash
   gcc -O0 Assignment1/time_complexity.c -o Assignment1/time_complexity.exe
   ```
   *(Note: The `-O0` flag is used to disable compiler optimization so that loops are not optimized away.)*
3. Run the compiled executable:
   ```bash
   ./Assignment1/time_complexity.exe
   ```
